# Laboratorio 6.3: PostgreSQL

## Objetivo

Implementar control de acceso basado en roles en PostgreSQL.

## Actividades

1. Crear la base de datos inventario.
2. Crear tablas.
3. Crear roles.
4. Crear usuarios.
5. Asignar permisos.
6. Probar accesos.
7. Revocar permisos innecesarios.

## Entregable

- Scripts SQL.
- Capturas de pantalla.
- Matriz de permisos.
