# Laboratorio 6.2: Oracle Database

## Objetivo

Crear usuarios, roles y privilegios en Oracle Database.

## Actividades

1. Crear un usuario.
2. Otorgar privilegio de sesión.
3. Crear un rol.
4. Otorgar permisos de lectura.
5. Asignar el rol al usuario.
6. Verificar los privilegios.
7. Revocar permisos.

## Entregable

- Script SQL.
- Capturas de pantalla.
- Explicación de privilegios.
