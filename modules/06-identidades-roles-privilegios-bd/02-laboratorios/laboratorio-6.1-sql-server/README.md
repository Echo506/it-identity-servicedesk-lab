# Laboratorio 6.1: SQL Server

## Objetivo

Crear usuarios, roles y permisos en Microsoft SQL Server.

## Actividades

1. Crear la base de datos EmpresaDB.
2. Crear las tablas clientes, productos y ventas.
3. Crear logins y usuarios.
4. Crear roles personalizados.
5. Asignar permisos según el perfil.
6. Probar el acceso.
7. Revocar permisos innecesarios.

## Entregable

- Scripts SQL ejecutados.
- Capturas de pantalla.
- Explicación de los permisos asignados.
