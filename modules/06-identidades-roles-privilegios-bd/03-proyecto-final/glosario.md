# Glosario

## Autenticación

Proceso que verifica la identidad de un usuario o aplicación.

## Autorización

Proceso que determina qué puede hacer un usuario autenticado.

## Usuario

Identidad que accede a una base de datos.

## Rol

Conjunto de permisos asignables a uno o varios usuarios.

## Privilegio

Permiso específico para realizar una acción.

## Menor privilegio

Principio que indica que cada usuario debe tener solo los permisos necesarios.

## Segregación de funciones

Separación de responsabilidades para reducir riesgos.

## Auditoría

Revisión de usuarios, roles, permisos y actividades realizadas.
