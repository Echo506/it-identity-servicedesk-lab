# Proyecto final: TechNova

## Escenario

La empresa TechNova necesita implementar un sistema de control de acceso para su base de datos.

Debes crear usuarios, roles y permisos para los siguientes perfiles:

- Administrador
- Analista
- Operador
- Consultor
- Auditor

## Requisitos

| Perfil | Permisos |
|---|---|
| Administrador | Crear tablas, insertar, actualizar, eliminar y administrar usuarios |
| Analista | Leer todas las tablas y ejecutar reportes |
| Operador | Insertar y actualizar registros de ventas |
| Consultor | Solo lectura de información pública |
| Auditor | Leer registros de auditoría sin modificar datos |

## Entregables

- Script SQL completo.
- Creación de usuarios y roles.
- Asignación de permisos.
- Pruebas de acceso.
- Revocación de permisos innecesarios.
- Matriz de control de acceso.
- Informe de seguridad.
