# Módulo 6: Identidades, roles y privilegios en bases de datos

Este repositorio contiene el material práctico del Módulo 6 del curso.

El objetivo es aprender a crear y administrar usuarios, roles y privilegios en bases de datos relacionales, aplicando el principio de menor privilegio y buenas prácticas de seguridad.

## Motores de base de datos

- Microsoft SQL Server
- Oracle Database
- PostgreSQL

## Contenido

- Fundamentos de seguridad en bases de datos
- Usuarios, roles y privilegios
- Control de acceso basado en roles
- Permisos sobre tablas, esquemas y vistas
- Auditoría de privilegios
- Proyecto final: TechNova

## Estructura

- `01-teoria/`: material teórico y guías.
- `02-laboratorios/`: laboratorios prácticos por motor de base de datos.
- `03-proyecto-final/`: proyecto integrador.
- `04-recursos/`: enlaces y glosario.

## Laboratorios

1. Laboratorio 6.1: SQL Server
2. Laboratorio 6.2: Oracle Database
3. Laboratorio 6.3: PostgreSQL
4. Laboratorio 6.4: Auditoría de privilegios

## Proyecto final

El proyecto final consiste en diseñar e implementar un modelo de control de acceso para la empresa ficticia TechNova.

Se deben crear usuarios, roles y permisos para los perfiles:

- Administrador
- Analista
- Operador
- Consultor
- Auditor

## Entregables

- Scripts SQL
- Capturas de pantalla
- Matriz de control de acceso
- Informe de seguridad
